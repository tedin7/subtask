## Notes
- Gas Town moved to gastownhall/gastown. Parallel Code identified by description (Electron, SolidJS, Claude/Codex/Gemini each in own worktree); no competing candidate found. "Orchestrator.inc" resolved through the GitHub org OrchestratorInc, whose repo homepage is orchestrator.inc; a near-identical Untrivial-ai/agent-orchestrator listing exists, canonical status between the two not verified.
- Only Claude Code (native or wrapped) documents a hard dollar cap that reaches background subagents. None of the four third-party tools documents any budget cap.
- None documents automatic cross-provider routing by quota or cost.
- Licenses for Claude Code and Codex not checked.
